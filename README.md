# Lärmcheck

Lärm-Risiko-Check für Trackdays (Hochschulprojekt, Vorabversion): Limit mit Quelle und Risiko-Ampel für Standtest und Drive-by. Feste Regeln, keine KI.

- `data/strecken.json`: Streckentabelle (Quelle und Lesedatum je Zeile)
- `rules.js`: Ampel-Regel v1
- `app.js`, `index.html`, `styles.css`: Oberfläche
- `npm test`: Testszenarien A–F

Live: https://s0ora.github.io/laermcheck/
